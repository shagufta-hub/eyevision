# EyeVision — Eyewear E-Commerce

Angular e-commerce store for **spectacles**, **goggles**, and **contact lenses** for **women**, **men**, and **kids** — priced in **Indian Rupees (₹)**.

## Features

- Home page with hero, category browse, and featured products
- Shop with filters (category, audience, search, sort)
- Product detail pages with quantity and variant selection
- Shopping cart with localStorage persistence
- Checkout flow with order confirmation

## Getting Started

```bash
npm install
npm start
```

Open [http://localhost:4200](http://localhost:4200).

## Build

```bash
npm run build
```

## Tech Stack

- Angular 16 (standalone components)
- SCSS
- RxJS & Angular signals for cart state
