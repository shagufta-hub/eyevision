🚀 QUICK START (2 MINUTES)

1. Run Database Migration:
   mysql -u root -p eyevision < backend/eyevision/src/main/resources/db_migration.sql

2. Configure Email:
   Edit: backend/eyevision/src/main/resources/application.properties
   Set:  mail.smtp.username=your-email@gmail.com
         mail.smtp.password=your-16-char-app-password

3. Build Backend:
   cd backend/eyevision
   mvn clean install

4. Run Server:
   mvn spring-boot:run
   (Server starts on http://localhost:8080)

5. Test with curl:
   # Place order (sends email)
   curl -X POST http://localhost:8080/api/orders/place \
     -H "Content-Type: application/json" \
     -d '{"customerName": "Test", "email": "test@gmail.com", ...}'

   # Get tracking
   curl http://localhost:8080/api/orders/1/track

   # Update status (sends email)
   curl -X PUT http://localhost:8080/api/orders/1 \
     -H "Content-Type: application/json" \
     -d '{"status": "SHIPPED"}'

Customer Places Order

         ↓
    CONFIRMED (Order confirmed by admin)
         ↓
    PROCESSING (Being prepared for shipment)
         ↓
    SHIPPED (On the way)
         ↓
    DELIVERED (Arrived at customer)

Optional: CANCELLED (at any point)

Note: Email sent at each status change

Statistics:

🎓 DATABASE SCHEMA

place_orders table:
  - orderId (Long, PK, Auto-increment)
  - customerName (String)
  - email (String)
  - phoneNumber (String)
  - productName (String)
  - quantity (Integer)
  - totalPrice (Double)
  - shippingAddress (String)
  - city (String)
  - zipCode (String)
  - paymentMethod (String)
  - status (Enum: PENDING, CONFIRMED, PROCESSING, SHIPPED, DELIVERED, CANCELLED)
  - createdAt (Timestamp)
  - updatedAt (Timestamp)

order_tracking table (NEW):
  - trackingId (Long, PK, Auto-increment)
  - orderId (Long, FK to place_orders)
  - status (String: order status at that time)
  - description (String: what happened)
  - createdAt (Timestamp: when status changed)

❓ TROUBLESHOOTING

Email Not Sending?
  → Check credentials in application.properties
  → For Gmail, use 16-char App Password (not regular password)
  → Check email spam folder
  → Check application logs for SMTP errors

Database Connection Error?
  → Verify MySQL is running on localhost:3306
  → Check database 'eyevision' exists
  → Run migration script
  → Verify username/password

Build Fails?
  → Check Java 17+ installed: java -version
  → Check Maven installed: mvn -version
  → Clear cache: mvn clean
  → Check internet connection

For detailed troubleshooting:
  → See COMPLETE_SETUP_GUIDE.md (Phase 10: Troubleshooting)
