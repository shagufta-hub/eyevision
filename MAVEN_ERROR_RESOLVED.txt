✅ QUICK SOLUTION (5 Minutes):
═════════════════════════════════════════════════════════════════════════

1. Download Maven
   → Go to: https://maven.apache.org/download.cgi
   → Download: apache-maven-3.9.5-bin.zip

2. Extract Maven
   → Right-click → Extract All...
   → Extract to: C:\Program Files\apache-maven-3.9.5\

3. Set Environment Variable (MAVEN_HOME)
   → Right-click "This PC" → Properties
   → Advanced system settings
   → Environment Variables
   → New... (in System variables)
   → Name: MAVEN_HOME
   → Value: C:\Program Files\apache-maven-3.9.5
   → Click OK

4. Update PATH Variable
   → Find "Path" in System variables
   → Edit...
   → New
   → Add: %MAVEN_HOME%\bin
   → Click OK

5. ⚠️ CRITICAL: Restart Terminal
   → Close Command Prompt / PowerShell completely
   → Open NEW Command Prompt / PowerShell

6. Verify Installation
   → Type: mvn -version
   → Should show: Apache Maven 3.9.5
